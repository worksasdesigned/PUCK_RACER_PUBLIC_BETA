## 🎯 What is this repository for?

**Feedback, Bug Reports, and Brilliant Ideas!** This project is currently in its **Closed Beta** phase. That means the system is alive, it's kicking, but it might still have a few quirks. We set up this public repository specifically to gather your feedback. 

If you are testing the PuckRacer system and something doesn't work as expected, or if you have a great idea for a new feature or game mode, please let us know! 

**How to help:**
1. Head over to the **[Issues](../../issues)** tab.
2. Check if someone else has already reported the same thing.
3. If not, open a new issue. Describe what happened, what you expected to happen, and how we can reproduce the glitch.

Don't hold back – your honest feedback helps make PuckRacer better for everyone!

## ⚡ Key Features of the PuckRacer System

For those curious about the tech and what the system can actually do, here is a quick rundown of the hardware and software features:

* **The Brains:** 1x ESP32-S3 acts as the Coordinator.
* **The Brawn:** 4 to 12x ESP32-C3 battery-powered Pucks.
* **The Flash:** Each Puck is equipped with 35 super-bright WS2812B LEDs.
* **The Input & Output:** Every Puck features a tactile Arcade button for inputs and a buzzer for acoustic feedback.
* **Lightning Fast Comms:** Real-time, ultra-low latency wireless communication between Coordinator and Pucks using **ESP-NOW**.
* **Easy Control:** The Coordinator hosts a web interface. The coach/trainer simply connects their smartphone to the Coordinator's Wi-Fi to manage everything—no external apps or internet connection required!
* **Packed with Games:** Includes about 20-25 different game modes specifically designed for physical education and athletic training.
